# Python Auction Program

This is a simple auction program built using Python. It allows multiple bidders to place bids on an item, and after bidding ends, the highest bid is announced along with the winner. The auction also checks that each new bid exceeds the current highest bid by a minimum increment, ensuring fair competition.

## Features:
- Users can place their bids by entering their name and bid amount.
- The program ensures that each new bid exceeds the current highest bid by at least a defined minimum increment.
- After all bids are placed, the winner and their bid amount are displayed.
- Input validation ensures that bids are positive integers, and bids cannot be placed below the minimum increment.
- Option to add multiple bidders, and the screen clears between bidders to simulate a real auction environment.

## Installation:

To run this program, you need Python installed on your system. If Python is not installed, you can download and install it from [Python.org](https://www.python.org/).
